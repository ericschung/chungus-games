Chungus Games: a static website (no server code). Upload this folder (or the zip) to any static host,
for example Cloudflare Pages (Workers & Pages > Create application > Drag and drop your files) or a
GitHub Pages repository. Open the address on the iPad in Safari, tap a game, then Share > Add to Home Screen.
The games load three.js and the fonts from the internet (cdn.jsdelivr.net, fonts.googleapis.com).
